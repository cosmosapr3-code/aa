# 片付けマスター3D SHOP - BGM

このフォルダは、ゲーム本体とは別に管理する追加BGM置き場です。

対応形式: `.mp3` / `.ogg` / `.wav`

音声ファイルをこの `music/` フォルダに追加してGitHubへコミットすると、ゲーム内の「BGM」一覧に自動で表示されます。ゲーム内でBGM画面を開き直すか、「曲一覧を更新」を押してください。

追加した曲は1曲500コインで購入して再生できます。購入済みの曲はセーブデータに記録されます。

最初から無料で選べる「おだやかな店内BGM」は、追加音声ファイルではなくWeb Audioでゲーム内生成します。そのため、このフォルダに最初から音声ファイルを置く必要はありません。

ファイル名は曲名として表示されます。例: `calm_piano.ogg`
